# NRG-2025-Dashboards
Overview of NRG's performance in VCT in 2025. Contains a main dashboard with general team stats, and five more, one for each player, essentially little player profile dashboards.

## What and why?
These are 6 PowerBI dashboards that can be used to glean insight into NRG's performance in 2025. Included are agent, map, and win rate statistics, for both the team as a whole and individual players. These are the first dashboards that I have created, and hopefully will serve as a benchmark for VCT data analysis.

### Tools used
- PowerBI, for the visualizations and the building of the dashboards
- Excel, to occasionally check the accuracy of statistics externally
